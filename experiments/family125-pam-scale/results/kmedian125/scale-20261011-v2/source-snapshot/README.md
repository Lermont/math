# FasterPAM / OneBatchPAM: 1 000--10 000 объектов

Отдельное продолжение первоначального пилота. План: [PLAN.md](PLAN.md), настройки:
[config.json](config.json). Итог: [REPORT.md](REPORT.md), создаваемый после анализа.
Старые исходники и результаты не изменяются. Данные синтетические, L1, два
seed данных и три seed алгоритмов. Контрольные случаи специально проверяют
редкие удалённые группы и одиночные точки.

Из корня `D:\projects\math`, в существующем `.venv-kmedian125`:

```powershell
& '.\.venv-kmedian125\Scripts\python.exe' -m unittest kmedian125.scale.test_scale -v
& '.\.venv-kmedian125\Scripts\python.exe' -m kmedian125.scale.run --run-id scale-replication-001
& '.\.venv-kmedian125\Scripts\python.exe' -m kmedian125.scale.analyze --run-id scale-replication-001
```

Новый запуск требует нового `--run-id`. Для прерванного контроллера:

```powershell
& '.\.venv-kmedian125\Scripts\python.exe' -m kmedian125.scale.run --run-id scale-replication-001 --resume
```

Завершённые строки не перезапускаются; перед продолжением проверяются хеши
замороженного кода. Не изменяйте файлы снимка и измерителя после начала опыта.
Анализ не запускает методы повторно. Все значения стоимости пересчитываются
по исходным координатам, включая точки, не попавшие в выборку OneBatch.

Версии библиотек и источники закреплены в исходном `../requirements.lock.txt`
и `../../references/kmedian125/sources.json`; новый запуск дополнительно
сохраняет хеши фактически установленных Python-файлов и бинарных модулей.
Новых внешних датасетов нет; оригинальные статьи и manifest не перезаписываются.

Оба метода получают float32-расстояния от одного блочного построителя. Полная
матрица не кешируется. Основное время включает её построение или построение
выборочных столбцов, а также fit. Импорты, холодный процесс, присвоение всех
объектов центрам и проверка стоимости измеряются отдельно. Память — фактический
пик рабочего набора процесса Windows сразу после fit, с импортами и буферами.
Для OneBatch используется нативный callable-distance путь без изменения ядра.

Качество сравнивается с медианой трёх FasterPAM решений на том же наборе.
Это относительное сравнение эвристик, а не доказанный разрыв до оптимума.
