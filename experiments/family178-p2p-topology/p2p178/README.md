# Локальный конструктор топологий и стенд P2P178

Проверка практической идеи из семейства №178 openai/math. Сравнивает кольцо,
случайный регулярный граф, ограниченный численный спектральный отбор и
классический LPS X^(5,13). **Алгоритм построения из статьи №178 не реализован.**
Все действия локальны; обращения к сети есть только в явно запускаемых
скриптах загрузки источников. Работающие P2P-сети и другие эксперименты
проекта не затрагиваются.

## Повторить пилот

Рабочая директория во всех командах — `D:\projects\math`.
Проверено на Windows 11, Python 3.14.7, NetworkX 3.7, NumPy 2.5.4,
SciPy 1.18.1, psutil 7.2.2. Для рисунка отдельно matplotlib 3.11.2.
Уже существующий `.venv-graph131` использован только как интерпретатор:
его пакеты и исходные файлы graph131 не менялись.

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
$env:OMP_NUM_THREADS = '1'
& .\.venv-graph131\Scripts\python.exe -m unittest discover -s p2p178/tests -v
& .\.venv-graph131\Scripts\python.exe -m p2p178.benchmark run --output results/p2p178/reproduction
& .\.venv-graph131\Scripts\python.exe -m p2p178.verify_results results/p2p178/reproduction
& .\.venv-graph131\Scripts\python.exe -m p2p178.summarize results/p2p178/reproduction
& .\.venv-graph131\Scripts\python.exe -m p2p178.write_report results/p2p178/reproduction
```

Каталог результата должен отсутствовать: существующие запуски не затираются.
Основной прогон на текущей машине занял около трёх минут, это наблюдение,
а не обещание времени на другом устройстве. Прогоны последовательные,
один поток BLAS, без affinity и фиксации частоты CPU. Время может меняться;
графы, сценарии и детерминированные модельные метрики при тех же версиях
должны воспроизводиться. Повторное агрегирование не требует симуляций:
`python -m p2p178.summarize ... --no-plot` работает без matplotlib.

Изолированное окружение на другом компьютере:

```powershell
py -3.14 -m venv p2p178/.venv
& .\p2p178\.venv\Scripts\python.exe -m pip install -r p2p178/requirements-plot.txt
```

После этого заменить путь интерпретатора в командах выше. Установка пакетов
требует сети; сами измерения её не используют.

## Устройство

| Файл | Назначение |
|---|---|
| `graphs.py` | Генераторы, компактная реализация классического LPS, численные LA/SA и точный целочисленный критерий статьи для n≤32. |
| `simulate.py` | Дискретные события, FIFO исходящего канала, flooding с кэшем, физические условия и отключения. |
| `benchmark.py` | Свежий процесс на каждое построение, отдельный процесс на пакет 6 симуляций; полные журналы кандидатов, wall time и RSS. |
| `tests/test_p2p178.py` | 11 проверок: независимый shortest-path oracle, FIFO, законы сохранения, известные/полные спектры, LPS, точный малый критерий. |
| `verify_results.py` | Проверка артефактов и общих условий; независимый dense-спектр 6 графов и аналитический спектр 25 колец. |
| `summarize.py` | CSV по сообщениям/повторам/построениям, JSON со всеми агрегатами, PNG/SVG с парными отношениями. |
| `write_report.py` | Русский отчёт и полные таблицы из сохранённых данных. Числовой рассказ предназначен для зафиксированного пилотного дизайна. |

Графы экспортируются как JSON с `n` и списком неориентированных рёбер,
вершины 0..n−1. Можно использовать их независимо от симулятора. Пример API:

```python
from pathlib import Path
from p2p178.graphs import generate, graph_bytes, spectrum
g = generate('random_regular', n=512, d=4, seed=17801)
Path('results/p2p178/example-graph.json').write_bytes(graph_bytes(g))
print(spectrum(g))  # численная диагностика, не формальный сертификат
```

Для нового дизайна скопировать `config.json`, зафиксировать отдельный план
и передать `--config путь`. `verify_results` и повествовательный отчёт
настроены на этот пилот (80 построений); для других дизайнов их нужно
адаптировать. Не выбирать параметры по уже полученным измерениям.

## Где данные

В `results/p2p178/pilot/` находятся `environment.json`, копии плана/config,
хеши кода, `tests.txt`, `raw.json`, `summary.json`, четыре CSV, PNG/SVG,
`verification.json`, отчёт и полные таблицы. `jobs/*/` содержит вход каждого
задания, все `candidate-*.json`, `attempts.json`, `build.json`, физические
трассы отказов/размещения/источников и `simulation.json`. У кандидатов
сохранены SHA-256, seed, время по этапам, спектральная невязка и причина отказа.
Поля с недостигнутыми порогами имеют JSON null / пустую ячейку CSV.

Память — максимум RSS дочернего процесса с импортами; главный процесс и
файловый кэш ОС не учтены. Пик симуляции относится к пакету из шести
сценариев. Исходные графы загружаются один раз на пакет; кэш ID и очереди
создаются заново для каждого сценария. Статистики времени t50/t95/t99 —
модельное время, `simulation_seconds` — фактическое время расчёта.

Загрузки источников отделены от воспроизведения:

```powershell
python -m p2p178.fetch_sources
python -m p2p178.fetch_comparators
```

Они сохраняют оригиналы и манифест с URL/SHA-256 под `references/p2p178/`,
не переписывают ранее сохранённые источники. Снимок main датирован; для
нового аудита создать новый датированный снимок и заново сверить коммит.
Лицензия исходников openai/math сохранена отдельно; наличие снимка внешнего
источника не меняет его лицензию. Код Julia не копировался в Python-перенос.
