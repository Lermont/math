# Линейные фильтры и семейство №325

Локальный воспроизводимый эксперимент для `exp(A)x` на синтетических
направленных графах и ненормальных матрицах. Используется скалярное следствие
теоремы о числовой области с константой 2. Способ построения диска и выбор
Taylor-полинома — собственный ограниченный прототип, не алгоритм из статьи.

## Воспроизведение

PowerShell, из `D:\projects\math`. Python 3.14.7; отдельная среда.
Если `.venv-filter325` уже существует, шаг создания пропускается.

```powershell
python -m venv .venv-filter325
.\.venv-filter325\Scripts\python.exe -m pip install -r filter325\requirements.txt
.\.venv-filter325\Scripts\python.exe -m unittest discover -s filter325 -p test_filter325.py -v
.\.venv-filter325\Scripts\python.exe -m filter325.benchmark --output results/filter325/reproduce --stage all
.\.venv-filter325\Scripts\python.exe -m filter325.audit --output results/filter325/reproduce
.\.venv-filter325\Scripts\python.exe -m filter325.report --output results/filter325/reproduce
```

`reproduce` должен быть новым каталогом. Команда не заменяет уже записанные
времена. Этапы также можно запускать последовательно `--stage data`, затем
`timing`, затем `memory`. Измерения последовательны, один поток BLAS/OpenMP.
Пиковая память снимается отдельным свежим процессом для каждой из 282 строк.
В этот период нельзя одновременно запускать вторую серию измерений.

Исходные бумаги уже сохранены локально. Необязательная повторная загрузка:

```powershell
.\.venv-filter325\Scripts\python.exe -m filter325.fetch_sources
```

Скрипт проверяет HEAD и останавливается при смене зафиксированного коммита,
не заменяет уже скачанные файлы. `audit` сверяет их SHA-256. Для одного
академического PDF на этой Windows-системе Python не достроил TLS-цепочку;
предусмотрена загрузка через штатный PowerShell с проверкой сертификатов.
Архив содержит также хешированные исходники реально установленной SciPy
1.18.1 и её лицензию; внешний HTML справки обозначен как 1.18.0.

## Файлы

`core.py` — рациональные сертификаты области/остатка и методы действия;
`data.py` — фиксированные генераторы и высокоточные эталоны;
`benchmark.py` — время, SpMV, предсказания и процессы памяти;
`audit.py` — независимая проверка сохранённых положительных свидетелей,
хешей, ошибок и сопоставления новой/старой констант;
`report.py` — таблицы и русское резюме из сырых измерений.

В `run-20261011/`: `data/`, `predictions/`, неизменённые
`measurements.jsonl` и `memory.jsonl`, объединённые JSON/CSV,
`preregistration.json`, версии/CPU, исходные и финальные хеши кода,
`tests.txt`, `validation.json`, `source-audit.json`, `summary.json`.

После первого запуска исправлена только ошибка названия производного поля
времени поиска степени (`replace` затрагивал часть слова `search`).
`audit` восстанавливает его из сохранённых сырых стадий. Выборка, степени,
предсказания и сырые времена не менялись; повторного подбора не было.

Граница полной float64-ошибки и независимая компиляция Lean/Comparator
не реализованы. Основная гарантия относится к полиномиальному усечению
в точной арифметике и опирается на теорему из зафиксированного источника.
